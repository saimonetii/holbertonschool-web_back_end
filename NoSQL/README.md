# NoSQL - MongoDB

Este proyecto contiene scripts de aprendizaje para el manejo de bases de datos NoSQL utilizando **MongoDB**.

## Tareas

| Archivo | Descripción |
| --- | --- |
| [0-list_databases](./0-list_databases) | Lista todas las bases de datos. |
| [1-use_or_create_database](./1-use_or_create_database) | Crea o usa la base de datos `my_db`. |
| [2-insert](./2-insert) | Inserta un documento en la colección `school`. |

## Requisitos
- MongoDB v3.6.3
- Ubuntu 18.04 LTS
